# Level 2 artwork

Generated with the built-in image-generation tool for the approved dental prototype. Source prompts are retained alongside the images. Petri-dish artwork replaces the older two-compartment dish cell. Mouthwash cells are unused. Production preparation deterministically resizes, trims and crops this artwork; it does not substitute drawn treatment imagery.

The browser prototype and unused loose-food sheet were removed after porting the level to Defold. Original generation prompts remain as provenance; some describe discarded concepts.
