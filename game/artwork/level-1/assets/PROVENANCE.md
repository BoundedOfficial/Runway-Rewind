# Original Level 1 artwork

All retained visible assets were generated for Runway Rewind. No extracted reference-game artwork is included. The dirty starting portrait was approved by the user; treatment plates were generated as registered variants. The final hair-only plate preserves the neutral expression. Clean clothing has its own generated plate and treatment.

The active set comprises ten character plates, one brush image, a 16-cell tool atlas, 38 transparent artwork sprites and 38 masks. Source names in the authoring manifest identify the reference artwork roles studied previously; they do not point to bundled reference files. The implementation is an adaptation, not verified native-game emulation.

`../authoring/prompts.json` preserves available generation prompts for retained plates. Historical reference paths in those prompts describe generation inputs, not runtime dependencies; some inputs were superseded and removed during cleanup. The optional generated `layer-map.csv` records the current source plates, registration and artwork hashes. The approved dirty endpoint predates this prompt log, and the brush/tool atlas were reused from earlier original generation work.
