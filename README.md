# Runway Rewind

The [Defold game](game/README.md) includes local setup, preview, and build instructions.
Preview the current development build at [localhost:5174](http://127.0.0.1:5174/) while the local server is running.
Release distribution goes through Playgama, including YouTube. A separate direct YouTube delivery is not part of the intended workflow.
The [Level 1 acceptance notes](docs/LEVEL-1-ACCEPTANCE.md) record the previous platform-specific compatibility checks and how to reproduce them.

Source artwork for both shipped levels is maintained in `game/artwork/level-1` and `game/artwork/level-2`. The obsolete browser prototypes have been removed.
